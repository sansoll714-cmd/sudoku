# 스도쿠 게임 PRD

## 1. 개요

- 제품명: 그린 스도쿠
- 목표: Node.js 기반으로 실행되는 웹 스도쿠 게임 구현
- 핵심 방향:
  - 전체 분위기는 초록빛 계열의 차분한 톤
  - 화면은 좌측 정보 영역, 우측 게임 영역의 2단 구조
  - 데스크톱 기준 스크롤 없이 주요 UI가 한 화면 안에 보여야 함

## 2. 제품 목표

- 사용자가 페이지 진입 후 바로 플레이를 시작할 수 있어야 함
- 게임 정보와 보드를 동시에 확인할 수 있어야 함
- MVP 기준으로 단순하고 빠르게 실행 가능한 구조를 유지해야 함

## 3. 대상 사용자

- 짧은 시간 동안 퍼즐을 가볍게 즐기고 싶은 사용자
- 별도 가입이나 복잡한 설정 없이 바로 시작하고 싶은 사용자
- 차분하고 깔끔한 UI를 선호하는 사용자

## 4. 기술 방향

- 런타임: Node.js
- 형태: Node.js 서버 + 브라우저 기반 웹 게임
- 우선순위:
  - 빠른 실행 가능성
  - 단순한 프로젝트 구조
  - 난이도, 기록, 추가 퍼즐 등 확장 가능한 구조

## 5. 화면 구조

### 5.1 전체 레이아웃

- 좌측 정보 패널, 우측 게임 패널로 나눈다.
- 주요 콘텐츠는 한 화면 안에서 확인 가능해야 한다.
- 데스크톱 우선으로 설계하되 작은 화면에서도 비율을 조정한다.

### 5.2 좌측 정보 영역

- 포함 요소:
  - 게임 제목
  - 난이도
  - 타이머
  - 힌트 사용량
  - 새 게임 / 힌트 / 초기화 버튼
  - 플레이 가이드

### 5.3 우측 게임 영역

- 포함 요소:
  - 9x9 스도쿠 보드
  - 선택 셀 강조
  - 관련 행/열/박스 강조
  - 같은 숫자 강조
  - 상태 메시지

## 6. UI/UX 요구사항

- 메인 컬러는 초록 계열을 사용한다.
- 전체 인상은 차분하고 깔끔해야 한다.
- 숫자 가독성이 가장 중요하다.
- 선택 상태, 오답 상태, 완료 상태가 명확하게 구분되어야 한다.
- 난이도 선택 UI는 전체 테마와 어울리도록 자연스럽게 표현되어야 한다.

## 7. 핵심 기능

- 새 게임 시작
- 쉬움 / 보통 / 어려움 난이도 선택
- 숫자 입력 및 삭제
- 정답/오답 기본 검증
- 힌트 제공
  - 최대 5회 사용 가능
- 타이머 표시
- 퍼즐 완료 판정
- 완료 시 난이도, 플레이 시간, 힌트 사용 횟수 표시

## 8. 반응형 및 해상도 요구사항

- 기본 기준은 데스크톱 한 화면 완전 노출
- 1280x800 이상에서 핵심 UI가 스크롤 없이 보여야 함
- 작은 화면에서는 패널 간격, 여백, 보드 크기를 비율로 조정

## 9. MVP 범위

- 포함:
  - Node.js 실행 환경
  - 좌측 정보 / 우측 게임 2단 레이아웃
  - 초록 테마 UI
  - 난이도별 퍼즐 제공
  - 입력 / 검증 / 힌트 / 완료 처리
- 제외:
  - 로그인
  - 온라인 랭킹
  - 멀티플레이
  - 모바일 앱 전용 기능

## 10. 성공 기준

- 사용자가 첫 화면에서 바로 새 게임을 시작할 수 있다.
- 정보 영역과 게임 영역이 동시에 자연스럽게 보인다.
- 난이도에 따른 체감 차이가 분명하다.
- 게임 완료 시 결과 정보가 명확히 제공된다.
